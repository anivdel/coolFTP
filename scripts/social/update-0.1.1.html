coolFTPv0.1.1
Update

The FTP client your coding agent can drive, now steadier on big sites.

Say "deploy this" in Claude Code, Codex or Cursor. Only changed files go up, the commit is recorded, the site is verified, and you watch it live in a desktop app.

  • Single-file pushes land in your project's web root, not next to it
  • Post-deploy checks hit the real public URLs
  • Dropped connections reconnect instead of re-uploading the whole site
  • Git Bash paths stop turning into C:\Program Files
