Update

Deploys your coding agent can undo, confirm, and read.

Say "deploy this" in Claude Code. Only changed files go up, the previous versions stay on the server, the site is checked afterwards, and you watch it live in a desktop app.

  • Undo without git. coolftp undo puts back what the last deploy overwrote
  • Confirmed uploads. Every file's size is read back from the server
  • Parallel FTP. Four connections for the big first deploy
  • Honest exit codes. Uploaded but not live is exit 3, never "success"
